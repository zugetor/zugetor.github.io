  2. 02

    Simplesoft CAN box

    The Simplesoft RP5-TY-101 sits between a Toyota’s CAN bus and an aftermarket head unit, turning vehicle messages into standard function IDs. This maps every ID and the byte layout behind it: doors, A/C, tire pressure, fuel use, steering-wheel keys.

    • Python
    • CAN bus
    • Toyota

  3. 03

    USB TPMS decoder

    Cheap USB tire-pressure receivers show up as a CH340 serial port and come with an Android app. The protocol was pulled out of that app and rebuilt as a Python decoder that reads pressure and temperature for all four tires and the spare, with leak, low-battery and no-signal alerts.

  4. 04

    Surface RT touchscreen over USB

    The touchscreen from a Microsoft Surface RT speaks HID over I2C. An STM32 Black Pill wired to the panel’s test points reads the mXT1386E digitizer, catches each touch interrupt and forwards it as a standard USB multitouch device, so the panel plugs into a computer like any USB touchscreen.

  5. 05

    DiscUtils HFS

    A fork of DiscUtils cut down to classic Macintosh media, with the bugs fixed that kept it from reading HFS+. It finds the Apple Partition Map, even with non-512-byte blocks, opens Apple_HFS wrapper partitions and mounts the HFS+ volume inside for browsing and extraction.
